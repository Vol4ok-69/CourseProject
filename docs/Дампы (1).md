У меня есть моя самописная программа для создания дампов. Вот ее описание(help):
treeq -h:
```
Description:
  Project tree viewer

Использование:
  ProjectTreeCli [options]

Параметры:
  -d, --depth <depth>                    Tree depth [default: 10]
  -e, --exclude <exclude>                Excluded folders/files
  -o, --only <only>                      Only extensions
  -c, --content                          Show file content
  -out, --output <output>                Output file path
  -f, --format <format>                  Export format [default: tree]
  -mfs, --max-file-size <max-file-size>  Maximum file size in KB [default: 512]
  -s, --size                             Show file and directory sizes
  --summary                              Show project summary
  --clipboard                            Copy output to clipboard
  --ignore-hidden                        Ignore hidden files
  -r, --references                       Show project-to-project references
  -p, --packages                         Show NuGet packages
  --include <include>                    Include only specified files/directories/globs
  --files-from <files-from>              Read included paths from a text file
  --exclude-pattern <exclude-pattern>    Excluded glob patterns
  --line-numbers                         Add line numbers to file content
  -?, -h, --help                         Show help and usage information
  --version                              Показать информацию о версии
```
Примеры использования:
```
treeq -out structure.md
treeq -c -out dump.md -e "README.md"
treeq -c -out project_dump.md -o ".cs" ".csproj" ".slnx"
treeq -p -r -out project_references_packages.md
treeq -c --include "Правила-базы-данных.txt;Исполнительное резюме анализатор БД.md;src/Analyzers/Database/DatabaseAnalyzer.cs;tests/DatabaseAnalyzer.Tests/DatabaseAnalyzerTests.cs" --line-numbers -out db_rules_review.md
treeq -c --include "src/Analyzers/Database;tests/DatabaseAnalyzer.Tests;src/Backend/Domain" --exclude-pattern "**/bin/**" "**/obj/**" --line-numbers -out db_analyzer_source.md
```
