# Матрица клиентских сценариев (CLI / Desktop / Telegram-бот)

| Сценарий | CLI | Desktop | Telegram-бот | Необходимые операции API | Статус реализуемости / Ограничения |
|---|---|---|---|---|---|
| Авторизация | Покрыто | Покрыто | **Частично покрыто** | `POST /api/auth/register`, `POST /api/auth/login` | Для бота не определена привязка `TelegramUserId`/`ChatId` (`TD016-F-013`) |
| Профиль | Покрыто | Покрыто | Покрыто | `GET /api/auth/me`, `PUT /me/username`, `PUT /me/password` | Реализуемо; OpenAPI-контракт требует обновления (`TD016-F-004B`) |
| Проекты (CRUD и список) | Покрыто | Покрыто | Список: покрыто; CRUD: не требуется | `GET/POST /api/projects`, `GET/PUT/DELETE /api/projects/{id}` | Списки без пагинации (`TD016-F-007`) |
| Настройка GitHub и синк | Покрыто | Покрыто | Синк: покрыто; PAT: не требуется | `GET/PUT/DELETE /api/auth/me/github`, `POST .../github/sync` | OpenAPI `SyncGitHub` устарел (`TD016-F-001`) |
| Коммиты и анализы (запуск, статус, история, результаты) | Покрыто | Покрыто | Покрыто | `CommitsController`, `AnalysesController` | `CreateCommitDto` OpenAPI устарел (`TD016-F-001`) |
| Отмена анализа | Требуется решение | Требуется решение | Не требуется | — | Открытый продуктовый вопрос (`TD016-F-013`) |
| Администрирование | Покрыто | Покрыто | Не требуется | `AdminUsersController` | Нет HTTP-интеграционных тестов мутаций (`TD016-F-011`) |
| Привязка Telegram и уведомления | Не требуется | Не требуется | **Требуется решение владельца** | — | Механизм привязки и push/polling не утверждён (`TD016-F-013`) |

## Оценка готовности (различие: старт разработки vs генерация SDK vs версионирование)
- **CLI (.NET 10 / Spectre.Console):** **Готово с ограничениями** — разработку логики и интеграции можно начинать, но **до генерации C# SDK** требуется стабилизировать OpenAPI (`TD017-001`: `operationId`, `ProblemDetails`, `Bearer` на `register`/`login`, актуальные DTO). Версионирование `/api/v1/` желательно согласовать, но не является жёстким блокером.
- **Desktop (Tauri / React / TypeScript):** **Готово с ограничениями** — UI-сценарии обеспечены; **до генерации TS-клиента** требуется стабилизировать OpenAPI (`TD017-001`). Отсутствие пагинации проектов (`TD016-F-007`) и `/api/v1/` не блокируют старт разработки.
- **Telegram-бот (.NET 10 / Telegram.Bot):** **Требует предварительной стабилизации / продуктового решения** — базовые команды чтения/запуска покрыты, но **до реализации бота** необходимо продуктовое решение владельца по привязке `TelegramUserId`/`ChatId` и доставке уведомлений (`TD017-010`).
